# Reference & attribution

Datastar StoraeBook is a small homage to **Storybook**
(https://storybook.js.org). Its UX conventions — a story tree in a
sidebar, a canvas that renders one story live, a toolbar over the canvas
(backgrounds), a docs/notes panel, and controls that change a story's
state in place — are adapted from Storybook's design.

No Storybook source is used or ported; this is idiomatic Aether +
Datastar. What we borrowed are the *ideas* and *interaction model*, which
is why the credit is "portions".

The stories, the harness, the components, and the StoraeBook UI are all
original Aether.
